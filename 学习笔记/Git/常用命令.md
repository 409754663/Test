# Git常用命令速查表

## 基础命令
| 命令 | 说明 |
|------|------|
| `git init` | 初始化仓库 |
| `git clone [url]` | 克隆仓库 |
| `git add [file]` | 添加文件 |
| `git commit -m "msg"` | 提交更改 |

## 分支操作
- `git branch`：查看分支
- `git checkout -b [branch]`：创建并切换分支
- `git merge [branch]`：合并分支

## 同步命令
- `git pull`：拉取更新
- `git push`：推送更改
- `git fetch`：获取更新

## 查看信息
- `git status`：查看状态
- `git log`：查看历史
- `git diff`：查看差异
